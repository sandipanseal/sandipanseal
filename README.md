#### 🎓 Master's Thesis — Explainable RF Jamming Analysis with an LLM Evidence Interpreter
***From RF Embeddings to Semantic Reasoning: Explainable Jamming Analysis via LLM-Based Evidence Interpretation*** · OVGU Magdeburg<br/>
Experimental study of how LLMs (as evidence interpreters) and conventional ML (as classifiers) perform on synthetic RF-jamming data. Five LLMs, one identical protocol. A supervised four-axis LDA evidence lifted regime accuracy from chance (**19% → 56%**, **73%** with a deterministic correction rule), citations were 100% grounded but **not always causally faithful** (paired perturbation tests, McNemar/Holm, group-aware bootstrap), and the same four LDA features without any LLM reach 80–81%: the representation, not the model, does the work.
<br/>`LLMs` `Explainable AI` `LDA` `Statistics` `Python`
